<summary>M2: Security Threats and Vulnerabilities</summary>

* Web Application Vulnerabilities
  * Client-side Vulnerabilities
    * Cross-Site Scripting (XSS)
    * Cross-Site Request Forgery (CSRF)
    * Cross-Origin Resource Sharing (CORS)
    * Clickjacking
  * Server-side Vulnerabilities
    * SQL Injection
    * OS Command Injection
    * Directory Traversal
    * Authentication Issues
    * Server-Side Request Forgery (SSRF)

</details>

<details>

<summary>M3: Protocol Engineering</summary>

* Open-Source Network Simulators (NS2 and NS3)
  * Installation and Configuration
  * Creation of Network Topology
    * Understanding Packet-Switched Networks
  * Simulation and Visualization of Traffic Types
    * Congestion-Controlled Traffic
    * Non-Congestion-Controlled Traffic
  * Trace Analysis and Visualization of Protocol Dynamics

</details>

<details>

<summary>M4: Implementing Network Security Protocols</summary>

* Active Queue Management
  * Simulation with Active Queue Management Schemes
* Attack Simulation and Visualization
  * IP Spoofing
  * Reflection Attacks
* Socket Programming
  * Implementation of IP Spoofing
  * Implementation of Reflection DDoS Attacks
* Linux Kernel
  * Familiarization with TCP/IP Protocol Implementation
  * Tracing and Debugging of Kernel TCP/IP Source Code
  * Kernel Modification and Recompilation
  * Implementation of a Non-Attack in Linux Kernel
* Network Emulation and Testbeds
  * Traffic Control using `tc`, Dummynet, and Advanced Tools
  * Advanced Testbed Technologies
    * Emulab
    * DETER
    * PlanetLab
  * Formal Verification of Protocols
    * SPIN
    * UPPAAL

</details>

<details>

<summary>M5: Design &#x26; Implementation of Penetration Testing</summary>

* Foundations
  * Causes of Vulnerabilities
  * Penetration Testing Tools
    * Using External Penetration Testers
    * Customizing Penetration Testing Tools
* Penetration Testing Process
  * Planning and Reconnaissance
  * Scanning of Ports
  * Penetration Testing Methods
  * Deep-Dive Analysis (External Testers)
* Post-Testing Activities
  * Feedback to Defect Management and Mitigation System
  * Scheduling Periodic Penetration Tests for Application Coverage
