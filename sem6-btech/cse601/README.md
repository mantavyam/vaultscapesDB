# CSE601 / DCCN

{% hint style="info" %}
Please be advised that Course IT601, offered within the B.Tech IT program, and Course CSE601, offered within the B.Tech CSE program, are substantively equivalent.&#x20;

* Both courses share identical syllabi, representing a direct parallel overlap.&#x20;
* The same faculty members instruct both courses.&#x20;
  * Therefore, resources for CSE 601 and IT 601, including previous year's questions, notes, and assignment questions, can be utilized interchangeably.
{% endhint %}
