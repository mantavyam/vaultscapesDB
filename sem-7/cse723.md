# CSE723 / Advanced PST Lab

### List of Experiments

1. WAP to use divide and conquer method to recursively implement Binary Search.
2. WAP to use divide and conquer method to recursively implement Linear Search.
3. WAP to use divide and conquer method to recursively implement and to find the maximum and minimum in a given list of n elements.
4. WAP to sort a given set of elements using the Merge sort method and determine the time required to sort the elements.
5. WAP to sort a given set of elements using the Quick sort method and determine the time required to sort the elements.
6. WAP to print all the nodes reachable from a given starting node in a given digraph using Depth First Search method.
7. WAP to Print all the nodes reachable from a given starting node in a given digraph using Breadth First Search method.
8. WAP to Implement 0/1 Knapsack problem using  dynamic programming.
9. WAP to Implement All Pair Shortest paths problem using Floyd's algorithm.
10. WAP to Find the Binomial Coefficient using Dynamic Programming.
11. WAP to find shortest paths to other vertices using Dijkstra's algorithm from a given vertex in a weighted connected graph.
12. WAP to Find Minimum Cost Spanning Tree of a given un-directed graph using Prims algorithm.
13. WAP to Find Minimum Cost Spanning Tree of a given un-directed graph using Kruskal's algorithm.
14. WAP to Implement N Queen's problem using Back Tracking.
15. Write a C/C++ program to simulate the following non-preemptive CPU scheduling algorithms to find turnaround time and waiting time.
    1. FCFS
    2. SJF
    3. Round Robin (pre-emptive)
    4. Priority.
16. Write a C/C++ program to simulate the following contiguous memory allocation techniques:
    1. Worst-fit
    2. Best-fit
    3. First-fit
17. Write a C/C++ program to simulate Bankers algorithm for the purpose of deadlock avoidance.
18. Write a C/C++ program to simulate page replacement algorithms&#x20;
    1. FIFO
    2. LRU
    3. OPTIMAL
19. Write a C/C++ program to simulate producer-consumer problem using semaphores.
20. Write a C/C++ program to simulate the concept of Dining-Philosophers problem.
21. Different DDL and DML Commands with Examples.
22. Demonstrate the concept of Key Constrains-Normalization.
23. Demonstrate different types of Aggregate functions.
24. Demonstrate the concept of Joins.
25. Demonstrate the concept of Views.
26. Demonstrate the concept of Index
27. Demonstrate the concept of PL/ SQL.
28. Demonstrate the concept of Exception handling.
29. Demonstrate the concept of Triggers.
30. Demonstrate the concept of Cursors
